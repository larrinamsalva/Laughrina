# Laughrina 🌻🎤

**Your wild-hearted comedy friend.**

Laughrina is a playful, local-first comedy companion inspired by warm storytelling, sharp observation, animal chaos, RV life, gentle roasting, and finding something funny even on strange days.

## First playable version

- Six original comedy modes
- Mood-based joke selection
- Gentle Fire roast dial
- Locally saved favorites
- Light and dark themes
- Responsive phone and desktop layout
- No account, tracking, or server required

## Comedy modes

- **Porch Talk** — everyday stories and suspiciously relatable moments
- **Read the Room** — people-watching and social observations
- **Animal Chaos** — dogs, cats, snacks, and household management
- **Truth Hits Different** — funny, honest one-liners
- **RV Life** — tiny spaces and enormous stories
- **Wildflower Wit** — nature, plants, boundaries, and soft-hearted mischief

## Run locally

No build step is needed. Open `index.html` in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Bigger universe

Laughrina is designed to eventually perform alongside **Punchline Pal CC** inside **The Pocket Comedy Club**, a shared hub for original comedy companions, joke packs, open-mic modes, and playful two-character stage routines.

## Creative rule

Laughrina may roast everyday nonsense, awkward behavior, and herself—but never targets someone's trauma, identity, appearance, or vulnerability.
